# Personal Expense Tracker

## Project Description

Personal Expense Tracker is a multi-form desktop application developed using C# and Windows Forms (.NET). It helps users manage and track their daily expenses in one place.

The application consists of two forms. The main form displays a list of all recorded expenses, while the second form allows users to add new expenses or edit existing expense details.

It provides a simple way to maintain expense records and understand daily spending.

## Features

- Add new expense records.
- Edit existing expense details.
- Delete expense records.
- Display all expenses in the main form.
- Enter expense title and amount.
- Select expense category.
- Select expense date.
- Validate user input before saving.
- Manage expenses using multiple forms.

## Technologies Used

- C#
- .NET
- Windows Forms (WinForms)
- Visual Studio
- SQLite Database (if implemented)

## Windows Forms Controls Used

| Control | Purpose |
|---|---|
| Form | Create multiple application windows |
| DataGridView | Display expense records |
| TextBox | Enter expense name and amount |
| ComboBox | Select expense category |
| DateTimePicker | Select expense date |
| Button | Add, edit, and delete expenses |
| Label | Display field names and information |
| MessageBox | Display confirmation and error messages |

## Application Forms

### 1. Main Form
The main form is used to manage and display expense records.

- Display all expenses.
- View expense details.
- Open the Add/Edit Expense form.
- Select an expense for editing or deletion.

### 2. Add/Edit Expense Form
The second form is used to enter or update expense information.

- Enter expense title.
- Enter expense amount.
- Select expense category.
- Select expense date.
- Save new expense details.
- Update existing expense details.
